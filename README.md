# CRM-Система на Django

## Описание проекта
Веб-приложение для автоматизации работы с клиентами. Система позволяет вести учёт услуг, запускать рекламные кампании, управлять потенциальными и активными клиентами, заключать контракты и отслеживать статистику эффективности рекламы.

## Стек технологий
* Python 3.10
* Django 5.2
* PostgreSQL (СУБД)
* Bootstrap (стилизация встроенной админки)
